## 為什麼做

伺服器的副本結算只會丟出一串數字，打完很難知道自己「到底打得好不好」。官網雖然有全服的統計資料，但要自己對照很麻煩。所以我做了這個模組：打完一場，馬上告訴你這場在全服排第幾百分位。

## 功能

- **自動結算**：解析聊天欄的戰鬥數據（灰色／綠色時間、傷害、承傷、治療），不用任何操作
- **四種 PR**：輸出、承傷、治療、通關速度分開計算，依職能（輸出／坦克／治療）各自比較，不會混在一起
- **突破頂峰**：超過全服 PR99 時顯示倍數（例如 PR100 ×1.35）
- **個人最佳**：每個副本記錄最速、最痛、最扛、最會奶的那一場，PR 一律用最新官方數據重算
- **賽季系統**：偵測官網版本更新（例如 V2.2 → V2.3）自動開新賽季，舊資料封存，可用指令回顧
- **圖表報表**：一鍵開啟本機 HTML 儀表板，看每場趨勢、最高與平均
- **補救工具**：認不出副本的場次先存起來，可用 `/prt fix` 補指定；誤記的場次可用 `/prt undo` 撤銷

## 技術重點

- Minecraft **1.21.11** + **Fabric**，約 25 個 Java 類別、4,600 行
- 背景執行緒抓官方統計、寫檔，不卡遊戲畫面；歷史紀錄做檔案快取
- 副本辨識：以結算時的首領名稱為主，聊天與計分板為輔；數值離譜（超過全服 PR99 五倍）視為認錯副本，不紀錄
- **防刷機制**：手動指定的副本必須跟首領名稱對得上，未經核對的場次只算個人紀錄
- 自架後端（Cloudflare Workers + D1）處理使用統計與賽季設定，模組端連不上也照常運作

## 成果

已在伺服器公開，玩家透過 Discord 頻道下載使用，持續依玩家回報更新（目前 v1.3.4）。

## 心得

最難的不是算 PR，而是「認對副本」和「資料可信」：伺服器訊息格式不固定、官網有時沒有新副本的資料，一個辨識錯誤就會讓數據暴增十倍。這個專案讓我學到要先假設資料會出錯，再一層一層加上檢查。
