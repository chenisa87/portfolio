Minecraft 商會備貨清單模組

Fabric 1.21.11 用戶端模組，在伺服器商會介面左邊加上「記錄收購」按鈕，自動讀出本週收購商品，面板直接顯示每樣還差幾個要準備。

JavaFabricMinecraft Mod

為什麼做

伺服器的商會每週收購的商品都不一樣，而且分成一般收購（有單價、預算、還能收幾個）和限量收購（只收一次、交完拿固定報酬）。每次都要一格一格把滑鼠移上去看說明，記不住到底要去準備什麼、還差多少。

功能

  • 打開商會時，介面左邊多一排按鈕：記錄收購、收起／展開、清空（清空要連按兩下，避免誤觸）
  • 按下「記錄收購」就把這一頁所有收購商品讀進清單，不用一個一個看說明
  • 旁邊的面板列出每個商品 還差幾個（可收數量扣掉背包持有），收滿或背包夠了會變綠色打勾、排到最後
  • 面板上方會算出「全部交完大約可以拿多少商會幣」
  • 之後每次打開商會，清單會自動更新剩餘可收數量
  • /gs 指令在聊天欄只列出「要準備的商品 × 數量」，不在商會時也能看

做法

  • 用 Fabric Screen API 在箱子介面初始化後加入按鈕，用 Mixin Accessor 取得介面的位置，讓按鈕和面板貼在介面左側
  • 讀取物品的名稱與說明文字（Lore），用正規表示式解析「收購／限量收購」、單價、預算、還能收、需求 × 數量、報酬、背包持有
  • 只有名稱是「收購 …」或「限量收購 …」、或寫了「需求」的物品才算商品，避免把說明文字、刷新按鈕誤認成商品
  • 解析邏輯獨立成不依賴 Minecraft 的類別，可以直接拿截圖上的文字寫測試
  • 清單存在本機 JSON，寫檔放到背景執行緒、先寫暫存檔再替換，遊戲不會卡

進度

  • 1.0.0：按鈕、面板、清單、指令
  • 1.0.1：支援限量收購；修正把說明文字當成商品的問題；/gs 精簡成只列要準備的商品和數量
