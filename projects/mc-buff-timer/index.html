Minecraft 技能計時模組

Fabric 1.21.11 用戶端模組，把技能 buff 的剩餘秒數直接疊在技能格上，快結束時變紅閃爍並響一聲，方便抓補技能的時機、節省魔力。

JavaFabricMinecraft Mod

為什麼做

伺服器的技能 buff 剩幾秒只用小圖示擠在畫面右上角，打怪時很難注意到，常常太早補（浪費魔力）或太晚補（buff 斷掉）。想要讓秒數直接出現在我正在看的技能圖示上。

找資料來源

一開始以為是原版藥水效果，但背包裡看不到。追下去才發現伺服器把 buff 寫在右側計分板的隊伍前綴裡，格式是 [技能名稱|剩餘時間]，時間有 24、1:30、16m 好幾種寫法。

功能

  • 技能格模式：秒數疊在每個技能圖示上方，圖示底部再加一條剩餘時間條；位置會自動對齊另一個 QoL 模組的技能 HUD
  • 自動配對技能 ↔ buff：大部分 buff 跟技能同名，但有不少例外（例如「黑狩犬」的 buff 叫「狼犬召喚」、「神聖戰吼」會給「獸化」），所以照官方天賦樹整理了一張約 40 個技能的對照表；同一個 buff 只會配給一格
  • 可以自己調：編輯畫面裡拖曳秒數改位置、點技能格手動指定要顯示哪個 buff、滾輪調大小
  • 剩幾秒以下變紅閃爍＋提示音（只對技能格上的 buff），10 秒內顯示到小數點
  • 開關按鈕／快捷鍵、清單面板模式、/bt debug 把計分板和快捷欄資料存成檔案方便除錯

技術

  • Minecraft 1.21.11 + Fabric Loader，Mojang 官方映射
  • 每 0.25 秒讀一次計分板，畫面上用時間差平滑倒數（計分板一秒才更新一次）
  • 解析與配對邏輯放在不依賴 Minecraft 的 core 套件，用實際抓到的資料寫小測試驗證

心得

第一版用「名字有共同字」去猜配對，結果常常配錯；還發現技能 HUD 的四格其實對應快捷欄第 2～5 格。最後是靠 /bt debug 把真實資料倒出來、再對照官方天賦樹，才把配對做準。教訓是：先拿到真實資料再寫規則。
